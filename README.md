# Hidden Bihar 🌍

Hidden Bihar is a full-stack travel website designed to help users explore and book travel destinations across Bihar.
The platform focuses on secure user access, rich destination content, and a responsive, user-friendly experience.
Each destination page features a dedicated weather card, detailed location information, a quick-glance overview,
a photo gallery showcasing the destination, and a small embedded map (iframe) for easy location preview and navigation.

---

## 🚀 Features

### 👤 User Features
- User authentication (Login & Signup)
- Secure access to protected pages
- Browse travel destinations
- Watch destination videos
- View destinations on an integrated interactive map
- Responsive design for mobile, tablet, and desktop devices

### 🛠 Admin Features
- Admin dashboard
- Upload and manage travel destinations
- Upload destination videos
- Control content visibility

### 🔐 Security
- Authentication-based access control
- Protected routes using middleware
- Environment variable protection using `.env`
- Secure session handling
